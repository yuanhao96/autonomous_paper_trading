# v2.2 — Cross-Sectional Validation

## Motivation

v2.1 computes a composite alpha score per stock, but we don't know if it actually predicts forward returns. This version adds validation: quintile analysis, composite IC measurement, and multi-horizon evaluation.

This is a **gate** — if the composite shows no signal, the downstream allocator (v2.3) is pointless.

## Bug Fix: Look-Ahead Bias in IC Weighting

The v2.1 `composite_alpha()` used `rolling_ic[t]` as the weight at date t. But `rolling_ic[t]` includes the IC computed from `factor(t)` vs `return(t→t+1)`, which requires knowing `return(t+1)` — information not available at time t.

**Fix**: Shift rolling IC by 1 day: `lagged_ic = rolling_ic.shift(1)`. Now `ic_weight[t]` uses only IC values computed through date t-1.

## Validation Framework

### Quintile Analysis

At each date:
1. Rank stocks by composite alpha into 5 groups (Q1=bottom, Q5=top)
2. Compute equal-weight forward return for each group
3. Measure: annualized return per quintile, long-short spread (Q5-Q1), monotonicity

### Composite IC

Daily Spearman rank correlation of composite alpha vs forward returns across all stocks. Summary stats:
- Mean IC: average daily IC
- IC t-stat: mean / (std / sqrt(n)) — statistical significance
- IC IR (Information Ratio): mean / std — risk-adjusted predictive power
- % Positive: fraction of days with IC > 0

### Multi-Horizon IC

Same IC computation at 1, 5, 10, 20-day forward return horizons. Reveals whether the alpha is short-term (decays by day 5) or medium-term (persists to day 20).

### Verdict

| Verdict | Criteria |
|---------|----------|
| STRONG | \|IC\| >= 0.03, \|t\| >= 3.0, monotonicity >= 0.75, spread > 0 |
| WEAK | \|IC\| >= 0.01, \|t\| >= 1.5, monotonicity >= 0.5 |
| NONE | Below WEAK thresholds |

## New Modules

### `validator.py` — Validation functions

- `form_quintile_returns(alpha, returns, n_groups, horizon)` → group return series
- `compute_quintile_stats(group_returns)` → annualized stats, spread, monotonicity
- `compute_composite_ic(alpha, returns, horizon)` → IC stats dict
- `multi_horizon_ic(alpha, returns, horizons)` → {horizon: IC stats}
- `evaluate_composite(ic_stats, quintile_stats)` → (verdict, reasons)

### `factor_validate.py` — Validate command runner

`run_validate()` orchestrates: load screen + factors → compute composite → quintile analysis → IC → multi-horizon → verdict → save + print report.

## CLI

```bash
python -m stratgen validate [--universe sp500] [--ic-window 60] [--top-n N]
    [--min-verdict MARGINAL] [--n-groups 5] [--horizons 1,5,10,20]
```

## Result Format

```json
{
  "composite_ic": {"mean_ic": 0.012, "ic_t_stat": 2.5, ...},
  "quintile_stats": {"mean_return_q1": -0.02, ..., "long_short_spread_ann": 0.05, "monotonicity": 0.75},
  "multi_horizon_ic": {"1": {...}, "5": {...}, "10": {...}, "20": {...}},
  "per_factor_ic": {"WQ-055": 0.023, ...},
  "verdict": "WEAK",
  "reasons": ["|IC| 0.012 < 0.03", ...]
}
```
